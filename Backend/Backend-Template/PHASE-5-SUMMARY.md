### 4. **Service Created** (1 file)
```
src/main/java/com/Hotel/service/
└── BookingService.java          # Core booking logic
```

**Core Method:** `createBooking(BookingRequestDTO, Long userId)`

**Transaction Flow:**
1. ✅ Validate user, hotel, and dates
2. ✅ Allocate specific rooms for each category
3. ✅ Calculate total pricing
4. ✅ Generate unique booking reference
5. ✅ Create Booking entity (PENDING status)
6. ✅ Create BookingRoom entries (lock rooms)
7. ✅ Return BookingResponseDTO

**Key Features:**
- `@Transactional` - Atomic all-or-nothing operation
- Unique reference generation: `BK-YYYYMMDD-XXXX`
- Price snapshot at booking time
- Comprehensive validation (dates, availability, hotel ownership)
- Maximum stay: 30 nights

## 💡 Key Technical Decisions

1. **Atomic Transactions**: Used `@Transactional` to ensure data consistency
2. **Price Snapshot**: Stored current price to prevent future price changes affecting existing bookings
3. **Specific Room Allocation**: BookingRoom table locks specific rooms (not just categories)
4. **Booking Reference Format**: Date-based prefix for easy sorting and debugging
5. **MapStruct**: Type-safe mapping with compile-time validation
6. **Validation**: Jakarta Bean Validation for declarative input validation
